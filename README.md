# JJL Garage Admin — Releases

Public release channel for the **JJL Garage Admin** desktop application.

This repository contains packaged application releases and update metadata only. The application source code, configuration files, business data, backups and credentials are not published here.

## Downloads

Use the **Releases** section to download the latest Windows installer.

## Updates

Installed copies of JJL Garage Admin use the public release metadata from this repository to check for updates. Updates are never installed silently and require explicit confirmation inside the application.

> Windows builds may currently show an **Unknown publisher / SmartScreen** warning because the installer is not yet Authenticode-signed.
